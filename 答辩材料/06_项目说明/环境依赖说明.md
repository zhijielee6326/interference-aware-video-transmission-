# 环境依赖说明

| 依赖 | 版本 | 用途 |
|------|------|------|
| Python | 3.12+ | 运行环境 |
| PyTorch | 2.10+ | CCNN 模型推理 |
| NumPy | 1.26+ | 数值计算 |
| SciPy | 1.12+ | 信号处理（RRC滤波等） |
| OpenCV | 4.9+ | 视频采集与 JPEG 编解码 |
| Matplotlib | 3.8+ | 实时可视化面板 |
| UHD | 4.x | USRP B210 驱动（仅实机模式） |

## 一键安装

```bash
pip install torch numpy opencv-python-headless scipy matplotlib
```
