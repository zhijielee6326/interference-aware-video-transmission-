# 代码运行说明

## 环境要求

- Python 3.12+
- PyTorch 2.10+ (CPU)
- numpy, opencv-python, scipy, matplotlib
- UHD（仅 USRP 实机模式需要）

## 安装

```bash
python3 -m venv venv
source venv/bin/activate
pip install torch numpy opencv-python-headless scipy matplotlib
```

## 运行

### 仿真模式（推荐）
```bash
cd 03_视频传输系统
../venv/bin/python3 run_system_with_viz.py
```

### USRP 实机模式
```bash
cd 03_视频传输系统
./run_demo.sh full
```

### CCNN 离线测试
```bash
cd 04_硬件测试验证
../venv/bin/python3 test_ccnn.py
```
